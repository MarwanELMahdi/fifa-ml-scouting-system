\# FIFA ML Scouting System



A complete Machine Learning system for FIFA player valuation and performance tier prediction using regression, classification, ensemble learning, and cross-validation techniques.



\---



\## Project Overview



This project was developed as part of a Machine Learning academic project focused on building a unified scouting and player analysis system using FIFA player data.



The system performs two main tasks:



\- Predicting player market value using regression models.

\- Classifying players into performance tiers:

&#x20; - Low

&#x20; - Mid

&#x20; - High

&#x20; - Elite



The project evolved from baseline ML models into an advanced ensemble-based scouting pipeline.



\---



\## Dataset Features



The dataset contains player information such as:



\- Name

\- Country

\- Overall Rating

\- Future Potential

\- Team

\- Market Value

\- Total Stats Score
